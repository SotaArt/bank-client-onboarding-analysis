# Анализ процесса подключения клиента к банковскому продукту

О проекте

Проект посвящён анализу текущего процесса подключения клиента к банковскому продукту и разработке улучшенной схемы взаимодействия между системами.

Цель проекта — сократить время обработки заявки, снизить количество ручных операций и повысить прозрачность процесса.

---

Основная проблема

В текущем процессе:

- данные вводятся вручную
- заявки передаются между подразделениями
- статус обновляется вручную
- возникают задержки
- возможны ошибки

---

Цель оптимизации

- автоматизация проверки клиента
- сокращение времени обработки
- снижение нагрузки на сотрудников
- единый статус заявки
- улучшение клиентского опыта

---

Используемые инструменты

- BPMN
- SQL
- REST API
- Business Analysis
- System Analysis
